# WorldTravel
Full-stack application where the frontend and backend are tightly integrated. On the frontend, i have used HTML, CSS and React to create an interactive user interface that adapts to different screen sizes using responsive design. The page includes interactive elements like buttons, forms, and dynamic content, which are powered by JavaScript. The back end was developed using Python language and the framework Django.

the webpage contains variour pages according to its funcionality
- Login, Register: File created for user can log in and register in the web page.
- index: Home page, first page that user access.
- destination: page where user can look all trips available.
- deals: page where user can look all deals available.
- details: page where user can look trip details (title, price, month available, images, description)
- layout: page that contain the header and footer of the web page
- mybooking:page where user can look his booking(month selected and the trip)
- wishlist: page where user can add any trip.
